1. избавляться от точек генерации исключений, запрещая соответствующее ошибочное поведение на уровне интерфейса класса;
   
№1  
Постоянная необходимость помнить о назначении водителя и машины друг другу могла бы превратиться в отдельный метод для согласования связи.
И конечно же это упростило бы удаление, вернее необходимость помнить об удалении ещё и связей.
```java
driver.setActiveVehicle(vehicle);
vehicle.setActiveDriver(driver);
```

```java
public class Vehicle {

    private Driver activeDriver;

    public void assignDriver(Driver driver) {
        if (driver == null) {
            throw new IllegalArgumentException("Driver must not be null");
        }

        this.activeDriver = driver;
        driver.assignToVehicle(this);
    }

    public void removeDriver() {
        if (activeDriver != null) {
            activeDriver.removeVehicle();
            activeDriver = null;
        }
    }
}
```
```java
public class Driver {

    private Vehicle activeVehicle;

    void assignToVehicle(Vehicle vehicle) {
        this.activeVehicle = vehicle;
    }

    void removeVehicle() {
        this.activeVehicle = null;
    }
}
```

3. -- избегать увлечения примитивными типами данных, разрабатывать прикладную систему типов, на смысловом уровне моделирующую предметную область
№1 
Один из наглядных для меня примеров: 

```java
@NotBlank
@Pattern(regexp = "^[А-Я]\\d{3}[А-Я]{2}$", message = "Формат номера должен быть А123БВ")
@Column(name = "license_plate", unique = true)
private String licensePlate;
```

```java
public Vehicle findByLicensePlate(String licensePlate) {
    return vehicleRepository.findByLicensePlate(licensePlate).orElse(null);
}
```
licensePlate уже является логической сущностью, но используется не как тип, а как обычная строка
Тогда можно было бы сделать из неё отдельный тип

```java
public record VehicleNumber(String value) {

    public VehicleNumber {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException("Номер автомобиля не должен быть пустым");
        }

        if (!value.matches("^[А-Я]\\d{3}[А-Я]{2}$")) {
            throw new IllegalArgumentException("Формат номера должен быть А123БВ");
        }
    }
}
```
и вызов:
```java
public Vehicle findByLicensePlate(VehicleNumber vehicleNumber) {
    return vehicleRepository.findByLicensePlate(vehicleNumber.value())
            .orElse(null);
}
```
